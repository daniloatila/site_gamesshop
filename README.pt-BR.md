# Games Shop

[Read in English](README.md)

Vitrine estática de uma loja fictícia de videogames, criada para praticar HTML e CSS. A página usa navegação por âncoras e Flexbox para organizar a apresentação da loja, o contato e a visita.

A [demonstração publicada](https://site-gamesshop-sepia-zeta.vercel.app/) mostra uma versão diferente do exercício. Siga os passos abaixo para visualizar os arquivos deste repositório.

## Executar localmente

Clone ou baixe o repositório e abra [`index.html`](index.html) no navegador. Não há etapa de compilação. A página carrega as fontes do Google Fonts quando há conexão e usa as fontes do sistema como alternativa.

- [`index.html`](index.html) contém a estrutura da página e os textos em português.
- [`main.css`](main.css) define o layout, a tipografia e os estilos do formulário.
- [`images/`](images/) contém a foto da fachada e as imagens de marcas.

O formulário de contato e os ícones de redes sociais fazem parte da demonstração visual. A página não tem checkout nem um serviço para processar o formulário. Use texto fictício para experimentar os campos.
