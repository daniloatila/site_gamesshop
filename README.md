# Games Shop

[Leia em português](README.pt-BR.md)

A static storefront for a fictional video game shop, built to practice HTML and CSS. The single-page layout uses in-page navigation and Flexbox to arrange the store information, contact form and location.

The [linked demo](https://site-gamesshop-sepia-zeta.vercel.app/) shows a different version of the exercise. Follow the steps below to preview the files in this repository.

## Run locally

Clone or download the repository, then open [`index.html`](index.html) in a browser. There is no build step. The page loads Google Fonts when an internet connection is available and falls back to system fonts.

- [`index.html`](index.html) contains the page structure and the Portuguese copy.
- [`main.css`](main.css) defines the layout, typography and form styling.
- [`images/`](images/) contains the storefront photo and brand imagery.

The contact form and social icons are layout samples. The page has no checkout or form backend. Use placeholder text to try the form.
